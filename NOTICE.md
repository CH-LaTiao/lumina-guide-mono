# Public prototype notice

LUMINA Guide Mono is a public engineering prototype for monocular scene
understanding and assistive cues. It is not a medical device and has not been
validated as a replacement for a white cane, guide dog, companion, or traffic
judgement.

The monocular distance values are estimates. Object distances use a pinhole
camera approximation and class-size priors. Scene distances use calibrated
relative monocular depth. Neither method is a safety-rated distance sensor.

This repository is a public demonstrator. It is not released under an open
source commercial licence, and no commercial-use or redistribution rights are
granted.
